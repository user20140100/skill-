# 通用测试方法论

需求驱动测试用例设计的通用方法论。

## 测试覆盖维度

| Type | Description | Example |
|------|-------------|---------|
| **正向功能** | Normal operation, valid inputs | 合法参数下功能正常执行 |
| **逆向功能** | Invalid inputs, boundary violations | 非法输入被正确拒绝或忽略 |
| **边界条件** | Min/max values, threshold crossing | 最小值、最大值、临界值处的行为 |
| **异常处理** | Sensor/hardware failure, communication error | 外部依赖故障时的降级与恢复 |
| **状态转换** | State switching, priority conflicts | 状态切换的条件、时序、互斥 |
| **组合场景** | Multiple functions active simultaneously | 多功能并发或交叉操作 |

## 测试用例优先级

| Priority | Description | Examples |
|----------|-------------|----------|
| **P0 (阻塞)** | 核心功能、安全保护、数据完整性 | 核心业务流程、安全保护机制、关键数据校验 |
| **P1 (严重)** | 主要功能、状态切换、精度要求 | 状态转换、计算精度、定时/调度功能 |
| **P2 (一般)** | 显示功能、用户交互、反馈提示 | 界面显示、按键响应、提示音/提示信息 |
| **P3 (建议)** | 极端场景、罕见组合、边缘情况 | 极端参数、罕见操作组合、低概率场景 |

## 命名规范

```
[模块]_[功能]_[场景]_[预期结果]
```

### 示例

| 用例标题 | 说明 |
|----------|------|
| `用户登录_密码校验_输入空密码_提示必填` | 逆向功能测试 |
| `订单提交_库存检查_库存为0_阻止下单` | 边界条件测试 |
| `数据导入_格式校验_CSV格式错误_报错并跳过` | 异常处理测试 |
| `权限管理_角色切换_从管理员降为普通用户_权限立即生效` | 状态转换测试 |

## 测试数据设计方法

设计测试数据时，对每个输入参数应用以下分析：

### 等价类划分

- **有效等价类**: 所有合法输入的代表值
- **无效等价类**: 所有非法输入的代表值
- 每个等价类至少选取一个代表值作为测试数据

### 边界值分析

- 最小值、最小值-1、最小值+1
- 最大值、最大值-1、最大值+1
- 空值/零值/默认值

### 状态组合

- 使用全对偶组合（pairwise）覆盖多参数组合
- 重点覆盖高风险组合（涉及安全、资金、数据的参数优先全覆盖）

> 领域特有的测试数据模板见对应的 `assets/*.md` 文件

## 测试用例模板

### 正向功能测试模板

```
用例ID: TC-XXX
用例标题: [模块]_[功能]_[正常场景]_[预期结果]
前置条件: 设备正常状态
测试步骤:
  1. 步骤一
  2. 步骤二
  3. 步骤三
输入条件: 具体输入参数
预期输出: 预期行为
测试类型: 正向
```

### 边界值测试模板

```
用例ID: TC-XXX
用例标题: [模块]_[功能]_[边界条件]_[预期结果]
前置条件: 设备正常状态
测试步骤:
  1. 设置边界值输入
  2. 观察系统响应
输入条件: 边界值参数
预期输出: 边界处理行为
测试类型: 边界
```

### 异常处理测试模板

```
用例ID: TC-XXX
用例标题: [模块]_[异常场景]_[异常条件]_[预期保护动作]
前置条件: 设备正常运行
测试步骤:
  1. 模拟异常条件
  2. 观察保护动作
  3. 模拟异常恢复
  4. 观察恢复行为
输入条件: 异常触发条件
预期输出: 保护动作及恢复行为
测试类型: 异常
```

### 状态转换测试模板

```
用例ID: TC-XXX
用例标题: [模块]_[状态A转状态B]_[转换条件]_[预期结果]
前置条件: 处于状态A
测试步骤:
  1. 触发转换条件
  2. 观察转换过程
  3. 验证新状态
输入条件: 转换触发条件
预期输出: 转换过程和新状态
测试类型: 状态转换
```
