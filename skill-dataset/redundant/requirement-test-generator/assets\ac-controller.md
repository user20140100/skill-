## 状态转换规则

### 基本转换规则

```
制冷模式 → 制热模式: 需要压缩机延时、四通阀切换
制冷模式 → 除湿模式: 风速自动切换为低风
制冷模式 → 送风模式: 压缩机停止
制热模式 → 制冷模式: 需要压缩机延时、四通阀切换
制热模式 → 送风模式: 压缩机停止，可能需要吹余热
任何模式 → 自动模式: 根据室温重新判定
```

### 自动模式判定规则

| 室温条件 | 进入模式 | 设定温度 |
|----------|----------|----------|
| RT ≥ 26℃ | 制冷模式 | 默认 25℃ |
| 20℃ ≤ RT < 26℃ | 送风模式 | - |
| RT < 20℃ | 制热模式 | 默认 25℃（单冷机型进入送风） |

### 时间约束

- **压缩机启动延时**: 停机后 3 分钟才能再次启动
- **模式最小运行时间**: 各模式需运行满 3 分钟才能切换
- **自动模式送风过渡**: 制冷↔制热需送风运行 15 分钟

## 常见测试场景

### 模式控制

1. 模式选择：验证各模式正确切换
2. 模式判定：自动模式根据室温正确选择模式
3. 模式互锁：验证模式间互斥逻辑
4. 模式记忆：断电后恢复原模式

### 温度控制

1. 温度设定范围：16°C-30°C，步进1°C
2. 温度显示：设定温度/室温切换显示
3. 温度控制精度：回差控制±1°C
4. 温度补偿：根据安装位置补偿

### 保护逻辑

1. 压缩机启动延时：停机后3分钟保护
2. 防冻保护：盘管温度 ≤ -1°C 触发
3. 防冻退出：盘管温度 ≥ 8°C 退出
4. 高温保护：冷凝器温度 ≥ 65°C 触发
5. 传感器故障：显示故障代码，按预设模式运行

### 显示功能

1. 温度显示：设定温度/室温正确显示
2. 故障代码：各故障对应正确代码
3. 运行指示：模式、风速、定时状态正确
4. 亮度调节：部分机型支持

### 定时功能

1. 定时开机：1-24小时可设定
2. 定时关机：1-24小时可设定
3. 定时组合：同时设定开关机
4. 断电记忆：定时设置是否保留
