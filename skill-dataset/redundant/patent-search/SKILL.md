# 智慧芽专利检索与差异分析

通过 Playwright 浏览器自动化操控智慧芽专利数据库，批量检索关键词、提取相似专利、分析差异点，最终生成结构化的检索报告。

## 前置条件

- 需要 Playwright MCP 工具（browser_navigate, browser_snapshot, browser_click 等）
- 用户需要有智慧芽账号（公司 OA 账号可 SSO 登录）

## 工作流程

### 第一步：协助用户登录

智慧芽需要登录才能使用。提供两种登录方式供用户选择：

**方式A：通过公司 OA SSO 登录**
1. 用 Playwright 打开 `https://oa.cvte.com`
2. 告诉用户："浏览器已打开 OA 登录页面，请完成登录。登录完成后告诉我。"
3. 用户确认后，导航到 `https://analytics.zhihuiya.com/search/input/simple`
4. 检查页面标题是否为"简单搜索 - 智慧芽"，确认登录成功

**方式B：用户自行登录后通知**
1. 用 Playwright 打开 `https://analytics.zhihuiya.com/search/input/simple`
2. 如果被重定向到登录页，告诉用户："需要登录智慧芽，请在浏览器中完成登录，然后告诉我。"
3. 用户确认后，刷新页面确认已进入搜索界面

登录成功的标志：页面 URL 包含 `/search/input/simple`，页面标题包含"简单搜索"或"智慧芽"。

### 第二步：确定检索关键词

与用户确认要检索的关键词列表。关键词通常来自：
- 专利交底书中的发明点
- 用户直接提供的关键词
- 从技术方案中提炼的核心概念组合

每个发明点建议准备 1-2 组关键词，每组 3-5 个词。如果精确关键词返回 0 条结果，自动扩大为更宽泛的同义词组合重试。

### 第三步：逐组执行检索

对每组关键词执行以下操作：

#### 3.1 构建搜索 URL 直接跳转

直接通过 URL 参数执行搜索比操作 UI 更稳定：

```
https://analytics.zhihuiya.com/search/result/tablelist/1?sort=desc&limit=20&q={URL编码的关键词}&_type=query&search_mode=publication
```

用 `browser_navigate` 直接跳转到搜索结果页。

#### 3.2 等待结果加载

搜索后等待 3 秒让结果完全加载：
```
browser_wait_for time=3
```

#### 3.3 提取结果数据

用 `browser_snapshot` 获取页面快照，从中提取：
- **总结果数**：在快照中查找 `共 N 条专利` 或 `≈ N`
- **专利列表**：查找 `CN[0-9]+[A-Z]` 模式的公开号和对应的标题文本
- **申请人信息**：在左侧列表区域查找申请人名称

如果结果为 0，用更宽泛的关键词重新搜索。

#### 3.4 关键词调整策略

| 结果数 | 策略 |
| --- | --- |
| 0 条 | 关键词太窄，去掉最专业的词，用同义词替换 |
| 1-20 条 | 理想范围，直接提取分析 |
| 20-100 条 | 可接受，重点看前 20 条 |
| >100 条 | 关键词太宽泛，增加限定词缩小范围 |

### 第四步：筛选相关专利

从每组检索结果中筛选与本提案最相关的 1-3 篇专利。筛选依据：
- 标题中包含与本提案相似的技术概念
- 申请人为同行业或相关领域企业
- 应用领域分类与本提案接近

不相关的专利（如标题明显属于其他领域）直接跳过。

### 第五步：分析差异点

对每篇筛选出的相似专利，分析其与本提案的差异。差异分析的维度：

1. **应用场景差异**：该专利面向什么场景？本提案面向什么场景？
2. **技术路线差异**：核心技术方案有何不同？
3. **创新点覆盖**：本提案的哪些创新点是该专利未涉及的？

差异描述要具体，避免泛泛而谈。每条差异点应明确指出"该专利做了什么"和"本提案做了什么不同的事"。

### 第六步：生成检索报告

输出 Markdown 格式的检索报告，包含：

```markdown
# 专利检索报告

> 检索平台：智慧芽（analytics.zhihuiya.com）
> 检索日期：YYYY-MM-DD
> 检索范围：全球数据库

## 一、检索记录汇总

| 序号 | 检索关键词 | 检索结果数 | 最相关专利 |
| --- | --- | --- | --- |
| 1 | xxx | ≈ N | CN...、CN... |

## 二、重点相似专利分析

### 2.1 CN... — 专利标题

| 字段 | 内容 |
| --- | --- |
| 公开号 | CN... |
| 申请人 | xxx |
| 相似度 | 高/中高/中/中低/低 |

**与本提案的不同点：**
1. ...
2. ...

## 三、检索结论

### 总体判断
（是否发现高度相似专利，本提案的差异化在哪里）

### 本提案的差异化创新点
（列出在检索范围内未发现对应专利的创新点）
```

## 注意事项

- 如果 Playwright 报 "Browser is already in use" 错误，尝试 `pkill -f "chrome.*--remote-debugging"` 后重试
- 智慧芽的搜索输入框是 `contenteditable` 的 div（class 为 `.editor-container`），不是普通 input
- 搜索结果页的专利号和标题分布在页面右侧列表中
- 每次搜索之间不需要回到首页，直接修改 URL 参数跳转即可
- 页面快照可能很大，用 `grep` 从快照文件中提取关键信息比全量读取更高效
