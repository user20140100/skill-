# 三. 安全规约

## 3-1 变量类型与数据安全

### 3-1-1 变量声明定义

3-1-1-1、\[SC]\[P] 变量定义时，请不要使用未定义长度（在不同平台下占用字节数不同）的基本类型变量，基本类型变量对应的跨平台兼容类型如下表，编码时统一使用跨平台兼容类型：

| 基本类型             | 标准的跨平台兼容类型         | 备注说明                                                                                         |
| ---------------- | ------------------ | -------------------------------------------------------------------------------------------- |
| bool             | bool               | 使用场景：逻辑运算变量<br><br>可读性：虽然在C/C++中0为false，非0为true。但为了代码可读性，逻辑运算统一用bool值（变量或表达式）。               |
| char             | int8_t/uint8_t     | 使用场景：二进制流、缓存区、像素值、带符号的传感器数据（int8_t）等。<br><br>可读性：为保证可读性，int8_t/uint8_t可以定义别名为char_t/uchar_t。 |
| short            | int16_t            | 使用场景：小范围带符号整数、音频采样值、16位色彩分量等。                                                                |
| unsigned short   | uint16_t           | 使用场景：小范围无符号整数、端口号、UTF-16编码字符等。                                                               |
| int              | int32_t            | 使用场景：大部分场景下使用的整数类型，不是非常大的数值。                                                                 |
| unsigned int     | uint32_t           | 使用场景：大部分场景下的无符号整数、位运算、计数等。                                                                   |
| long / long long | int64_t            | 使用场景：大范围整数、大数据、高精度的场景。                                                                       |
| unsigned long    | unit64_t           | 使用场景：无符号的大范围整数，UUID、硬件地址、毫秒时间戳等。                                                             |
| 指针               | intptr_t/uintptr_t | 使用场景：内存地址计算                                                                                  |
| float            |                    | 说明：float没有对应标准的跨平台类型，在大部分平台下占4个字节。用于精度要求不高的场景。                                               |
| double           |                    | 说明：double没有对应标准的跨平台类型，在大部分平台下占8个字节。用于高精度场景。                                                  |
说明：C语言要包含头文件<stdint.h>、<stdbool.h>，C++要包含头文件\<cstdint>。项目中允许对这些标准的跨平台兼容类型起别名。

3-1-1-3 \[SC] 变量在使用前必须进行初始化，最好的初始化时机是在定义时，否则在使用前要检查是否已经初始化。

### 3-1-2 变量使用

3-1-2-1、\[SC]\[P] 变量的格式化输入/输出，要严格按照下表进行，否则在不同平台中会因为长度不匹配出现输入/输出数据越界、截断等错误：

新的format

3-1-2-2、\[SC]\[P] 宏常量、枚举在参与计算、格式化输出时，要根据上下文选择合适的类型进行显示类型转换，否则在不同平台下隐式转换为不同类型，可能导致数据错误。


3-1-2-3、\[SC] 对外部提供的接口，在未知数据范围情况下，需要进行数据防溢出检查，检查规则如下：
a.无符号整数，如uint32_t：
```
if (a > UINT32_MAX - b) {
    // a + b出现上溢
}

if (a < b) {
    // a - b出现下溢
}
```

b.有符号整数，如uint32_t
```
if (((b > 0) && (a > INT32_MAX - b))) {
    // a + b出现上溢
}

if ((b < 0) && (a < INT32_MIN - b)) {
    // a + b 出现下溢
}

if (((b > 0) && (a < INT32_MIN + b))) {
     // a - b出现下溢
}

if ((b < 0) && (a > INT32_MAX + b)) {
    // a - b出现上溢
}
```

c.浮点数：使用头文件<math.h>中的isinf(x)判断是否上溢（INFINITY无穷大），isfinite(x)判断是否有限值，isnan(x)判断是否无效运算（NaN无效值），如：
```
if (isinf(a * b)) {
    // a * b上溢
}
```

3-1-2-4、\[SC] 请不要将宽式类型（占用字节数较多的）变量隐式转换为窄式类型（占用字节数较少的）变量，请不要出现有符号数与无符号数之间的隐式转换。且使用显示类型转换前，必须校验宽类型变量、无符号类型变量的在转换后是否会溢出。

【可以使用，但必现要校验】

3-1-2-5、\[SC] float/double类型变量请不要用于双等号'\=='比较。
说明：计算机中的浮点数是由符号位、尾数、阶码组成，其中尾数为有效数字，精度有限，无法准确的等于某个数值。
