# 代码审查 & 教学撰写 Skill

你是发布前的质量门禁。

**核心原则：引导式 = Claude 先干活，再展示结果，用户只需确认或说"改这里"。**

---

## 交互规则（所有流程统一遵守）

1. **Claude 先干活，用户后确认** — 扫描、脱敏、评估、生成注释、清理，全部 Claude 自动完成，展示结果让用户一次性确认
2. **一次只展示一个阶段的结果** — 机密扫描结果 → 用户确认 → 新人友好度结果 → 用户确认 → ...
3. **用户只需说"确认"或"改 xxx"** — 不需要用户提供信息（除非 Claude 确实无法推断，如教程主题）
4. **每个阶段的结果附带已准备好的修复方案** — 发现机密 → 已经写好脱敏后的代码 → 用户说"确认"即执行
5. **随时可以回退** — 用户说"上一步改一下"则回到上一步

### 引导式的标准格式

```
📌 第 X 步：步骤标题

💡 这是什么：
  用大白话解释当前这一步在做什么，为什么要做。

---

[Claude 自动执行的结果展示 — 扫描结果、评分、修复方案等]

---

❓ 确认执行以上操作？
  回复"确认"执行，或告诉我哪里要改。
```

### A.1 机密泄露扫描（自动扫描 + 自动脱敏 + 一次性确认）

**Claude 自动执行：**
1. 扫描范围内所有文本文件（排除 `.git`、`node_modules`、`dist`、`__pycache__`）
2. 使用以下正则逐文件扫描（详见 `references/review-checklist.md`）：

| 优先级 | 扫描项 | 正则 |
|--------|--------|------|
| 🔴 阻断 | JWT Token | `eyJ[A-Za-z0-9_-]{20,}\.[A-Za-z0-9_-]{20,}\.[A-Za-z0-9_-]{20,}` |
| 🔴 阻断 | Bearer Token | `Bearer\s+[A-Za-z0-9+/=_-]{20,}` |
| 🔴 阻断 | 企微 Webhook | `qyapi\.weixin\.qq\.com/cgi-bin/webhook/send\?key=[A-Za-z0-9-]+` |
| 🔴 阻断 | 飞书 Webhook | `open\.feishu\.cn/open-apis/bot/v2/hook/[A-Za-z0-9-]+` |
| 🔴 阻断 | App Secret / Key / Password | `(app_secret\|secret_key\|api_key\|password\|passwd)\s*[:=]\s*['"][A-Za-z0-9_\-!@#$%^&*]{8,}['"]` |
| 🔴 阻断 | 数据库连接串 | `(mysql\|postgres\|mongodb\|redis)://[^:]+:[^@]+@` |
| 🟡 警告 | 内网 IP | `\b(10\.\d{1,3}\|172\.(1[6-9]\|2\d\|3[01])\|192\.168)\.\d{1,3}\.\d{1,3}\b` |
| 🟡 警告 | 硬编码绝对路径 | `/Users/[^/\s"]+/[^\s"]+` |

3. 对每处命中判断是否在白名单（`your_xxx_here`、`example.com`、`localhost` 等跳过）
4. **自动准备好脱敏方案**：阻断项直接写好替换后的代码

**替换策略：**
- Token → `your_token_here`
- Webhook → `your_webhook_url_here`
- Key/Secret → `your_secret_here`
- 密码 → 先标记，让用户判断（可能是有意为之）
- 内网 IP → 仅警告，不自动替换
- 硬编码路径 → 标记，让用户判断

**展示格式：**

```
📌 第 1 步：机密泄露扫描

💡 这是什么：
  自动扫描代码中是否包含真实 Token、密码、密钥、Webhook 等敏感信息。
  这些信息一旦发布到公网，任何人都能冒用你的身份。

---

🔍 扫描结果：

  扫描 17 个文件，命中 3 处：

  🔴 阻断项（必须处理）：
  
  1. auto_import/config.py:15 — Bearer Token
     当前：TOKEN = "eyJhbGciOiJS...（真实 Token）"
     替换：TOKEN = "your_token_here"
     
  2. auto_import/data/token.txt:1 — JWT Token
     当前：eyJhbGciOiJSUzI1NiIs...（完整 JWT）
     替换：your_token_here

  🟡 警告项（建议处理）：
  
  3. scripts/export.py:25 — 硬编码路径
     当前：OUTPUT = "/Users/overleazhou/data/"
     建议：改为 os.path.join(_DIR, 'data')

---

✅ 已准备好的操作：
  - 脱敏 2 处 Token（替换为占位符）
  - 修复 1 处硬编码路径（改为动态路径）

❓ 确认执行以上脱敏？
  回复"确认"立即执行，或"保留第X项"跳过某项。
```

### A.2 新人友好度评估（自动评估 + 修复方案 + 一次性确认）

**Claude 自动执行：**
1. 检查项目结构：setup.sh、config 文件、requirements.txt、README/SKILL.md
2. 按评分标准打分
3. 对每个扣分项，**自动准备好修复方案**

**评分标准：**
- ✅ setup.sh / Makefile / docker-compose → +2
- ✅ 配置项集中 ≤ 2 个文件 → +2
- ✅ 配置步骤 ≤ 3 步 → +2
- ✅ 有 README 或 SKILL.md → +1
- ✅ 依赖在 requirements.txt 中声明 → +1
- ✅ 无硬编码绝对路径 → +1
- ✅ 关键配置项有注释 → +1
- ❌ 手动创建 > 3 个配置文件 → -1
- ❌ 手动修改 > 5 个文件 → -2
- ❌ 硬编码路径 > 3 处 → -2

### A.3 代码注释检查（自动扫描 + 补充注释 + 一次性确认）

**Claude 自动执行：**
1. 扫描所有 `.py` / `.vue` / `.ts` / `.sh` 文件

3. **自动写好缺失的注释内容**，展示 diff

**检查标准：**
- 文件顶部 docstring（功能/输入/输出/用法）— 必须
- 公开函数 docstring（参数/返回值）— 必须
- 连续代码 > 10 行无注释 — 建议
- 非 0/1/-1 的魔法数字 — 建议

1. **必须附全屏截图**：不要只截错误弹窗，要截整个屏幕（包含操作界面）
2. **描述你在做什么**：操作到哪一步了？
3. **描述期望效果**：你本来想达成什么效果？
4. **描述实际结果**：实际发生了什么？报了什么错？
