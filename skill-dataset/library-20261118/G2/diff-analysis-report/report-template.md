## 模板使用说明（勿写入最终报告）
- 报告版本固定 V2.1；禁用 Emoji
- 1.3 为条件章节，无需求文档时整节省略并在末章注明；「用例覆盖」列无用例文档时省略
- 第三章风险「类型」列可带归属标签（所属需求 / 版本性），多需求混装分支必标
- 第五章为条件章节，无用例文档时整节省略并在末章注明
- 第二章未发现的问题不展开明细
- 第四章只放三方差异用例；常规回归不在本章（由业务背景文档与风险专项补充覆盖）
- 报告直接创建为飞书在线文档（不经本地 md 报告文件中转，主交付物）；无法创建时才落本地 md，并在回复中说明原因（操作方法见 SKILL 步骤 9）
