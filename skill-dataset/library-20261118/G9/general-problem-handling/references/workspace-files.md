# Personal Workspace Files

本文件只定义 `personal-local-v1` 的本地文件契约。`managed-agent-v1` 继续使用 `artifact-contracts.md` 的完整契约。

## 目录

```text
.trouble-shooter/<issue-id>/runs/<run-id>/
├── issue.md
├── plan.md
├── facts.md
├── analysis.md
├── review.md
└── result.md
```

- `issue-id` 优先使用用户给出的稳定编号；没有时生成不包含正文的短标识。
- `run-id` 使用时间戳或短随机标识。
- 所有正文默认只保存在当前工作目录。

## 必需标题

### issue.md

- `# 问题输入`
- `## 现象`
- `## 影响范围`
- `## 环境与时间`
- `## 执行环境`
- `## 已知约束`
- `## 业务 Skill`

### plan.md

- `# 排障计划`
- `## 已知输入摘要`
- `## 候选假设`
- `## 决策树总览`
- `## 本案默认路径`
- `## 所需证据`
- `## 停止条件`

### facts.md

- `# 事实记录`
- `## 已确认事实`
- `## 来源锚点`
- `## 工具错误与缺口`

每条事实包含编号、观测内容、来源、观测时间和异常标记。推断不得写入本文件。

### analysis.md

- `# 推断分析`
- `## 问题陈述`
- `## 已确认事实`
- `## 直接触发原因`
- `## 根因与缺陷定性`
- `## 支持与反对证据`
- `## 置信度`
- `## 遗留缺口`

### review.md

- `# 独立复审报告`
- `## 复审立场`
- `## 逐项审查`
- `## 反例与未排除候选`
- `## 复审结论`
- `## 遗留风险`

### result.md

- `# 排障结论`
- `## 问题摘要`
- `## 排查思路与事实`
- `## 分析判断`
- `## 最终结论 / 根因`
- `## 建议动作`
- `## 复审记录`
- `## 置信度`
- `## 排查归因`

## 阶段门禁

进入下一阶段前，检查上游文件存在且所有必需标题下至少有一项有效内容：

| 下一阶段 | 必须通过的文件 |
|---|---|
| plan | `issue.md` |
| collect | `issue.md`、`plan.md` |
| inference | `facts.md` |
| review | `analysis.md` |
| result | `review.md` |

缺失时先补齐当前文件；无法补齐则停止并向用户列出缺失标题。禁止退化为无文件记录的完整排障。

## 中断恢复

1. 列出 `<issue-id>/runs/` 下已有 run，不读取其他 issue。
2. 对选中 run 只检查六个约定文件，并按上表识别最后完成阶段。
3. 向用户展示 run-id、最后阶段和已知限制，让用户选择继续或新建。
4. 继续时从下一阶段开始，并复用 `issue.md` 已记录的工具路径；实际调用前仍检查文件可执行。
5. 新建 run 时不复制旧 `facts.md`、`analysis.md` 或 `review.md`。如需引用旧结论，只在新 `issue.md` 标注为“待重新验证的历史线索”。
