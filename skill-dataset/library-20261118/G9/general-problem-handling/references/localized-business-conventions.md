# 本地化业务约定知识

仅当入口 `SKILL.md` 已确认问题属于“本地化 / 边缘 / 高职教”业务语境时读取本文件。这三个名称表示同一个业务语境。

## 默认知识

- 系统只有一个超级管理员：手机号为 `11000000000`，用户 UID 为 `4a778e0a070940aa950db42d4d97b76b`。
- 系统只有一所学校，其 `unitId` 固定为 `002`。
- 用户的 `unitId` 为 `001` 时，表示该用户没有组织归属。
- 用户能否看到某个模块由权限控制；模块不可见通常表示该用户没有对应权限。
- 系统会为每个学期的排科计划默认生成一个全校作息表，这个逻辑在mofangyun-local，如果没有生成则代表流程有问题
- 需要区分unitId跟机构码的概念，一般机构码可能叫inviteCode，学校uid也就是unitId，也可能叫schoolId之类的，查询数据库的时候不要混淆两个概念

## 证据优先级

上述内容是本地化业务的约定默认知识，不是本次排障中已经执行查询得到的事实。写入排障产物时必须标注来源为本 reference。

用户明确提供的当前环境信息或工具实际观测与默认知识冲突时，以当前证据为准；在 `facts.md` 和 `analysis.md` 中记录冲突双方、来源与采用当前证据的理由，不得用默认知识覆盖实际事实或据此输出错误的高置信结论。
