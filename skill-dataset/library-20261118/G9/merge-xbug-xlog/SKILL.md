# merge-xbug-xlog

用于合并xbug的xlog中指定文件夹内的日志碎片，合成成完整的日志文件。

## 使用场景

商显DSU的Android交互平板设备日志（FS/data/misc/xlog）通常按大小分割并压缩存储（`log_0.gz`, `log_1.gz`, ...）。该工具自动化解压与合并流程。

## 命令

### 快速使用

```bash
# 指定目录，解压并合并
bash merge-xlog.sh "/path/to/xlog/directory"
```

### 示例

```bash
bash merge-xlog.sh "~/Downloads/xbug/FS/data/misc/xlog/5_2026-04-09_200649"
```

## 工作流程

1. **验证目录** — 检查是否存在 `.gz` 文件
2. **获取目录名** — 以目录名作为输出文件名（添加 `.log` 后缀）
3. **解压** — 逐个解压，保留原始文件（`gunzip -k`）
4. **排序** — 按文件名数字排序（`log_0`, `log_1`, ...）
5. **合并** — 按顺序拼接所有内容到输出文件
6. **清理** — 删除解压出来的中间产物（`log_0`, `log_1`, ...）
7. **验证** — 报告文件数、行数、大小

## 参数

| 参数 | 说明 | 必需 |
|------|------|------|
| `$1` | 包含 `.gz` 文件的目录路径 | ✓ 必需 |

**说明：** 必须提供目录路径，脚本不会自动搜索。

执行权限：`chmod +x merge-xlog.sh`

## 注意事项

- ✓ 保留原始 `.gz` 文件（不删除）
- ✓ 输出文件名与目录名一致，添加 `.log` 后缀
- ✓ 自动删除解压出来的中间产物（`log_0`, `log_1`, ...）
- ✓ 仅合并 `log_*` 格式的文件（忽略其他文件）
- ⚠ 必须提供目录参数，不提供时会拒绝执行
- ⚠ 如果输出文件已存在，会被覆盖
