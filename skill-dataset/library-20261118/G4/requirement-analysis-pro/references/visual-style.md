## 1. 视觉原则

1. 业务语义优先于装饰；没有信息价值的装饰删除。
2. 一张图只保留一个视觉焦点和一个主阅读方向。
3. 外层分区承担结构识别，内部节点保持轻量，形成“外重内轻”。
4. 颜色必须与形状、边框、线型和标签共同表达语义，不能作为唯一编码。
5. 同一篇文档使用同一预设、字号档位和稳定语义色。
6. 一张图通常使用 2～4 个分组色；异常、风险和待确认使用固定语义。

## 2. 默认预设

默认采用“清新商务”，适合需求评审和屏幕阅读。用户提供的模板、品牌规范或参考成品优先；同一份需求文档只选一个视觉预设，不因图型变化切换色板。

| 角色 | 色值/规格 |
|---|---|
| 画布 | `#F8FAFB` |
| 内容节点 | `#FFFFFF`，边框跟随所属分组，圆角 8～12px |
| 主标题/正文 | `#1F2329` |
| 次要文字 | `#646A73` |
| 中性连线 | `#BBBFC4`，2px |
| 支撑层 | `#F5F6F7`，边框 `#DEE0E3` |

分区使用同色浅底和深色边框；内部节点以白底为主。高饱和色只用于标题栏、关键标签、少量强调和边框。

用户明确要求时可切换：

- 商务低饱和：正式评审、制度和架构材料；
- 科技暗色：AI、算法或技术展示；
- 极简黑白：打印、审阅和低干扰场景；
- 品牌风格：使用用户品牌色，但不得覆盖异常和风险语义。

## 3. 语义色

### 3.1 统一分组与语义色

| 色 | 主色 | 浅底 | 推荐语义 |
|---|---|---|---|
| 蓝 | `#5178C6` | `#F0F4FC` | 第 1 系统/分组、入口或公共能力 |
| 紫 | `#8569CB` | `#EAE2FE` | 第 2 系统/分组、协同或规则能力 |
| 绿 | `#509863` | `#DFF5E5` | 正常、目标、完成或已通过 |
| 橙 | `#D4B45B` | `#FEF1CE` | 判断、变化、提示或待决策 |
| 红 | `#D25D5A` | `#FEE3E2` | 真实异常、阻断或风险 |

同一业务域或阶段一旦选色，全文保持一致；内部普通节点仍优先白底。

### 3.2 固定语义

| 语义 | 填充 | 边框 | 文字/线型 |
|---|---|---|---|
| 开始/正常结束 | `#DFF5E5` | `#509863` | `#1F2329` |
| 系统自动动作 | `#F0F4FC` | `#5178C6` | `#1F2329` |
| 人工活动 | `#FFFFFF` | 所属分组色 | `#1F2329` |
| 判断/待决策 | `#FEF1CE` | `#D4B45B` | `#1F2329`，菱形 |
| 异常/阻断 | `#FEE3E2` | `#D25D5A` | `#1F2329` |
| 待确认 | `#FFFFFF` | `#BBBFC4` | `#646A73`，虚线 |

正常主线使用中性实线；异常、回退和补偿使用红灰虚线，并标注返回节点。红色不得用于普通能力、普通人工活动或装饰强调。

## 4. 图表样式

### 4.1 蓝图与架构

- 一张图只选择价值流、能力、系统或数据中的一个主视角。
- 业务蓝图按“业务结果 → 价值流/场景 → 能力 → 系统与数据支撑 → 治理”组织。
- 数据架构按“来源 → 集成 → 资产与治理 → 服务 → 消费”组织。
- 系统边界图将核心系统置于中心或范围框内，上下游按业务方向分区。

### 4.2 流程与泳道

- 主路径优先左到右，异常支路靠近触发点并置于主线下方。
- 泳道使用极浅底和轻边框；角色通过泳道标题和边框区分，不使用整条高饱和底色。
- 一个活动只放在一个责任泳道，跨道箭头表示真实交接。
- 判断分支写完整条件，汇聚点明确，箭头不穿过节点或文字。

### 4.3 ER、状态、对比与路线

- ER 实体白底，按业务域使用边框色；字段只保留主键、外键和关键属性。
- 状态节点保持同色，事件写在线上；异常状态红边，终态绿边。
- As-Is/变化/To-Be 使用相同维度逐行对齐；变化动作使用有限强调色。
- 里程碑沿单一时间轴推进，每阶段标注交付物、退出条件和业务结果。
- 数据图必须写指标、单位、时间、口径和来源，不使用 3D、渐变或装饰图标。

## 5. 画布与文字

| 项目 | 建议值 |
|---|---:|
| 画布宽 | 1100～1400px |
| 图标题 | 26～32px |
| 分区标题 | 16～18px |
| 节点正文 | 14～16px |
| 注释/线标签 | 12～14px |
| 四周安全边距 | ≥32px |
| 节点内边距 | ≥12px |
| 同层节点间距 | ≥24px；有连线时 ≥40px |

- 坐标、尺寸和间距优先使用 8px 倍数；同层节点等宽等高。
- 长名称最多两行，并在业务语义边界换行；仍超出时增大节点或拆图。
- 连线位于节点下层，优先正交折线；无法消除交叉时调整节点或拆图。

## 6. 出图前检查

- [ ] 阅读方向、视觉层级和重点清楚。
- [ ] 字号、颜色和间距一致，文字与连线无明显遮挡。
- [ ] 图中的范围、关系、编号和结论与正文一致。
