**课题名称：AI Agent 技能（Agent Skills）全链路安全审计与效果评估系统**

1. **业务背景** 团队正在大规模引入第三方及内部开发者编写的 Agent Skills（如用于 Claude Code、Codex、OpenCode 的技能文件夹）。除了格式规范和效果难以量化外，安全团队近期提出了严重的合规担忧：

    1. **技能投毒与隐蔽风险**：Skill 文件夹不仅包含 Markdown 指令，还常附带执行脚本。恶意或编写不当的 Skill 可能隐藏**提示词注入（Prompt Injection）、越权工具调用、敏感凭证外泄或后门命令**；

    2. **语义冲突与冗余**：不同 Skill 的指引存在高度重叠，导致 Agent 触发逻辑混乱；

    3. **行为增益不明确**：缺乏沙盒隔离环境下的对照实验，无法证明某个 Skill 确实提升了 Agent 的任务完成率，而非引入副作用。



2. **核心任务** 请调研业界针对 **Agent Skills 安全扫描与多层行为评估** 的开源解决方案，在本地 Mac 环境中搭建原型系统，并完成以下交付：



- **阶段一：技术调研与环境搭建**

    - 在本地 Mac 环境完成全套依赖安装（包括底层的安全扫描器组件与 Docker 沙盒环境），配置 LLM API Key 并跑通官方基准示例。

- **阶段二：攻防测试与三层评估实战**

    - 对上述 3 个 Skill 运行完整评估流水线，验证系统能否：**精准拦截风险样本并给出安全审计报告 \-\> 识别出冗余冲突 \-\> 在 Docker 沙盒中量化正向 Skill 对 Agent 的真实行为增益**。
