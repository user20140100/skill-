## 一、现场查杀（核心演示）

```bash
# 1. 选一个安全靶场 Skill（含硬编码凭证 / 隐蔽外泄 / 提示注入）
ls skill-dataset/security/

# 2. 无 LLM 快速静态扫描（零成本）
skillspector scan ./skill-dataset/security/<恶意skill> --no-llm

# 3. 输出 JSON/SARIF 报告，展示风险评分与 findings
skillspector scan ./skill-dataset/security/<恶意skill> --format json --output reports/demo.json
```

**讲解要点**：逐条指出被命中的威胁类别（提示注入 / 数据外泄 / 凭证访问），对照报告的风险评分 0-100。

## 二、三层评估演示

```bash
# Tier 1：安全扫描 + 质量评分
uv run --python 3.13 --extra all skillevaluator validate ./skill-dataset/positive/<正向skill> --tiers 1

# Tier 2：语义去重（冗余拦截）
uv run --python 3.13 --extra tier2 skillevaluator tier2 ./skill-dataset/redundant/<冗余skill> --catalog ./reports/redundant-catalog.json

# Tier 3：沙盒增益（带/不带 Skill 对照）
uv run --python 3.13 --extra tier3 skillevaluator tier3 ./skill-dataset/positive/<正向skill>
```
