# 企业管理系统页面与原型输入规范

## 1. 适用范围与输出模式

以下情况读取本文件：

- 新增或重构工作台、列表、详情、表单、审批、配置、监控或 Agent 交互；
- 页面包含多角色权限、字段联动、状态驱动操作、批量处理或复杂异常；
- 一个页面承载多个功能，或一个功能跨多个页面；
- 用户明确要求页面原型、OpenDesign/AI 原型工具输入或前端设计交接。

纯后端规则、接口、批处理、定时任务或无界面 Agent 不创建页面规格。

### 1.1 两种输出模式

| 模式 | 使用条件 | 输出位置 |
|---|---|---|
| 需求正文模式 | 默认；页面用于补充功能交互 | “系统功能”章的页面与导航总览、`PAGE-xxx` 页面规格 |
| 独立原型包 | 用户明确要求原型工具输入或完整页面设计交接 | 独立 `prototype.md`，引用正文编号，不复制业务事实 |

### 1.2 按需求类型裁剪

| 需求类型 | 页面深度 |
|---|---|
| 项目型 | 页面地图、核心工作台、主流程页面、关键配置页、异常中心及必要 Agent 交互 |
| 专项 | 新增和受影响页面、关键交互链路、状态和权限 |
| 变更型 | 目标页面、组件、变更前后和影响状态；通常不画整套系统 |

## 2. 功能与页面边界

### 2.1 映射规则

- `FR-xxx` 描述系统必须提供的可观察行为。
- `PAGE-xxx` 描述功能在页面中的信息、操作、状态和反馈。
- `FR` 引用相关 `PAGE`；`PAGE` 列出承载的 `FR`。
- 页面不得重新定义 `BR`、数据对象和接口契约，只引用其编号。
- 同一页面的布局、字段和状态只定义一次，避免在多个功能项重复。

功能—页面映射表：

| 功能编号 | 功能名称 | 页面编号 | 页面作用 | 无页面载体 |
|---|---|---|---|---|
| FR-xxx |  | PAGE-xxx | 查询/操作/配置/监控 | 接口/批处理/任务/Agent 后台 |

### 2.2 输入前置

页面设计前至少确认：

1. 关联 `OBJ/SCN/BR/FR` 和业务结果；
2. 所属系统、模块、导航位置和上下文入口；
3. 核心对象、字段、状态、规则、权限和数据范围；
4. 关键操作、前置条件、执行结果、异常和反馈；
5. 桌面 Web、移动端、工作台或嵌入式页面等终端约束。

缺失项标「待确认」，不得由原型工具补造字段、按钮或规则。

## 3. 页面地图与页面规格

### 3.1 页面与导航总览

项目型或多页面专项按需输出：

```text
<一级菜单>
├── <业务工作台>
├── <业务对象列表>
│   ├── <对象详情>
│   │   ├── 概览
│   │   ├── 明细/过程记录
│   │   ├── 关联对象
│   │   └── 操作日志
│   └── <新建/编辑>
├── <任务与异常中心>
└── <配置管理>
```

页面清单：

| 页面编号 | 页面名称 | 页面类型 | 系统/模块 | 入口 | 关联功能 | 主要角色 | 新增/修改 |
|---|---|---|---|---|---|---|---|

### 3.2 `PAGE-xxx` 页面规格

```markdown
#### PAGE-xxx <页面名称>

**关联功能**：FR-xxx
**关联场景/规则**：SCN-xxx / BR-xxx

##### 页面目标
<角色>在<场景>下完成<任务>，并获得<结果>。

##### 入口与退出
- 入口：<菜单/列表行/消息/关联对象/深链>
- 前置条件：<权限、对象状态、数据条件>
- 完成后：<返回、跳转、刷新、消息或后续任务>

##### 页面布局
1. 页面头：<标题、对象编号、状态、主操作>
2. 筛选/摘要区：<筛选器、指标、风险提示>
3. 主工作区：<表格、表单、看板、流程、详情>
4. 辅助区：<侧栏、活动记录、智能助手、帮助>

##### 组件、字段与操作
<引用组件表、字段表和操作表>

##### 状态与反馈
<加载、空、错误、无权限、处理中、成功、冲突>

##### 权限与数据范围
<页面、字段、操作、组织和数据范围>

##### 验收
<引用 AC；必要时补充 Given/When/Then>
```

## 4. 企业管理系统页面类型

### 4.1 工作台/驾驶舱

工作台服务任务聚合、异常处置和业务跟进，不是营销首页。

```text
页面标题 + 组织/工厂/时间口径 + 主要动作
关键指标（通常 3～6 个）
待办与异常（优先级、SLA、责任角色）
业务进度/趋势（可下钻）
最近处理或关注对象
```

| 指标 | 业务口径 | 数据源 | 组织/时间范围 | 展示格式 | 预警阈值 | 下钻行为 |
|---|---|---|---|---|---|---|

指标必须可解释、可下钻；异常优先于装饰性图表。

### 4.2 列表与检索页

```text
面包屑/标题/主操作
常用筛选 + 高级筛选
结果摘要/已选条件
数据表格
批量操作/分页
```

| 列名 | 字段标识 | 宽度 | 格式/单位 | 排序 | 筛选 | 冻结 | 权限/脱敏 | 点击行为 |
|---|---|---:|---|---|---|---|---|---|

同时定义默认排序、默认筛选、保存视图、导出权限、批量上限、行操作条件和无结果提示。制造业列表按需包含组织、工厂、仓库、物料、订单、工单、批次、状态和业务时间。

### 4.3 详情页

```text
对象名称 + 编号 + 状态 + 主操作
关键信息摘要
Tab：概览｜明细｜流程/任务｜关联对象｜附件｜操作日志
活动时间线/审计记录
```

主操作随状态变化，只展示当前允许的操作。字段按业务主题分组，不按数据库字段顺序排列。

### 4.4 新建/编辑表单

| 字段标签 | 字段标识 | 控件 | 必填条件 | 默认值 | 数据源 | 校验 | 联动 | 编辑权限 | 帮助文本 |
|---|---|---|---|---|---|---|---|---|---|

必须说明保存草稿、提交、取消、未保存提示、重复提交保护、接口失败、并发冲突和敏感操作二次确认。

### 4.5 主从/明细编辑页

适用于销售订单、采购订单、合同、BOM、工单、检验单等“头信息 + 明细行”对象：

- 头部字段按业务主题分组；
- 明细定义新增、复制、批量粘贴、导入、校验、汇总、删除和行级错误；
- 数量、单位、工厂、库存地点、批次、交期和版本字段必须说明联动；
- 提交前显示错误汇总，并可定位到具体行和字段；
- 明细量大时使用虚拟滚动或分页，不把所有字段横向铺开。

### 4.6 分步向导

| 步骤 | 目标 | 字段/组件 | 进入条件 | 完成条件 | 可返回 | 保存策略 |
|---|---|---|---|---|---|---|

步骤条展示进度和错误；修改前序步骤可能影响后续数据时，必须提示影响并重新校验。

### 4.7 审批与任务中心

| 项目 | 要求 |
|---|---|
| 任务列表 | 优先级、SLA、对象、发起人、组织、当前节点 |
| 业务摘要 | 申请内容、规则命中、风险和历史意见 |
| 操作 | 同意、驳回、退回、转交、加签、撤回 |
| 约束 | 必填意见、下一节点、权限、状态、通知和撤销条件 |

### 4.8 配置管理页

规则、字典、模板、阈值和策略配置应展示版本、生效范围、生效时间、状态、引用数量和最后修改信息，并支持复制、启停、发布和回滚。已被引用的配置不可直接删除。

### 4.9 监控与异常中心

优先呈现“需要处理什么、影响什么、如何恢复”：

| 字段 | 要求 |
|---|---|
| 异常类型/等级 | 枚举和判定规则 |
| 业务对象 | 可回到订单、物料、工单、批次或接口任务 |
| 影响范围 | 交期、库存、生产、质量、财务或客户影响 |
| 责任角色/SLA | 当前处理责任和剩余时间 |
| 建议动作 | 系统、规则或 Agent 给出的下一步 |
| 处理状态 | 待处理/处理中/已恢复/已关闭 |

## 5. 组件、字段与操作

### 5.1 组件表

| 组件编号 | 组件名称 | 类型 | 数据来源 | 展示规则 | 交互 | 状态 | 权限 |
|---|---|---|---|---|---|---|---|

### 5.2 操作表

| 操作 | 载体 | 显示条件 | 前置校验 | 执行动作 | 成功反馈 | 失败/补偿 | 权限 |
|---|---|---|---|---|---|---|---|

载体选择：

| 任务 | 推荐载体 |
|---|---|
| 独立、复杂、需分享链接 | 新页面 |
| 保留上下文的查看或轻编辑 | 右侧抽屉 |
| 简短确认或少量字段 | 模态弹窗 |
| 高频单字段修改 | 行内编辑 |
| 批量处理 | 专用批量面板或页面 |
| 解释、建议和证据 | 侧栏或可展开区域 |

危险操作必须展示影响对象、关键参数、能否撤销和失败后果，不能只提供“确认/取消”。

## 6. 状态、权限与数据映射

### 6.1 页面状态

| 状态 | 页面表现 | 可用操作 | 恢复方式 |
|---|---|---|---|
| 加载 | 骨架屏/进度 | 可取消或返回 | 自动完成 |
| 空 | 原因和下一步 | 新建/调整筛选 | 用户操作 |
| 无权限 | 缺少的权限 | 申请/返回 | 授权后恢复 |
| 接口失败 | 原因和影响 | 重试/降级 | 自动或人工 |
| 并发冲突 | 新旧数据差异 | 刷新对比/重新提交 | 用户确认 |
| 处理中 | 任务进度和查询入口 | 查看后台任务 | 异步完成 |
| 成功 | 结果对象和状态变化 | 查看对象/继续处理 | 不适用 |

关键业务动作不能只用 Toast；还应显示结果对象、状态、后续任务和审计编号。

### 6.2 权限与数据范围

| 页面/组件/字段/操作 | 角色 | 可见 | 可编辑 | 可执行 | 数据范围 | 脱敏 | 例外 |
|---|---|---|---|---|---|---|---|

数据范围按需考虑本人、团队、部门、BG、法人、工厂、仓库、产线和指定组织。前端可见性和服务端校验必须一致。

### 6.3 数据与接口映射

| 页面组件 | 字段/指标 | 来源对象/接口 | 刷新时机 | 加载策略 | 缓存 | 错误降级 |
|---|---|---|---|---|---|---|

列表、详情和表单中的同一字段使用同一业务定义。指标引用统一口径；接口未定义时标「待确认」，不伪造 URL。

## 7. AI Agent 交互

Agent 页面围绕业务任务设计，不默认使用通用聊天界面。用户可见交互引用 `AGT/TOOL/KNW/EVAL`，不重复定义后端运行规则。

```text
业务上下文：对象、目标、状态、风险
任务与计划：用户意图、步骤、进度、等待和失败
证据：数据来源、文档引用、计算依据
建议与动作：建议、影响预览、需确认操作
运行记录：工具调用、结果、接管、审计和终止原因
```

| 组件 | 要求 |
|---|---|
| 建议卡 | 结论、置信度、证据、影响和可编辑内容 |
| 动作确认 | 动作、对象、参数、权限、能否撤销和失败后果 |
| 计划进度 | 当前步骤、已完成、等待、失败和下一步 |
| 工具调用 | 工具/系统、目的、结果摘要和敏感信息控制 |
| 人工接管 | 暂停、修改、驳回、重试和转人工 |
| 反馈 | 采纳、修改、拒绝及原因 |
| 降级 | 无模型、无知识或工具失败时切换规则/人工流程 |

付款、合同、主数据、BOM/ECO、库存、生产、质量、权限和删除等高风险动作默认需要人工确认。界面明确区分“建议”“待确认执行”“执行中”“已执行”“执行失败”。

## 8. 独立原型输入包

仅在用户明确要求时输出：

```markdown
# 原型任务：<系统>/<范围>

## 1. 业务上下文与范围
## 2. 关联 SCN/BR/FR/DATA/AC
## 3. 信息架构与页面地图
## 4. PAGE 页面规格
## 5. 组件、字段与操作
## 6. 状态、权限与数据范围
## 7. AI Agent 交互（按需）
## 8. 验收场景
```

原型描述使用确定性业务语言，避免只写“专业、现代、高级”。禁止营销式 Hero、装饰性大卡片和无业务含义插画。原型工具不得推断业务字段、规则、按钮和流程。

## 9. 交付前检查

- [ ] 页面、字段、操作与对应 `FR-xxx` 一致，没有新增未经确认的业务规则。
- [ ] 页面结构和主要操作清楚，关键状态与反馈可理解。
- [ ] 变更型需求只覆盖受影响区域；无页面功能没有被强行页面化。
- [ ] 高风险操作和 Agent 执行保留必要的人工确认或失败处理。
