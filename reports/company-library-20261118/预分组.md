## 推荐优先级（用于寻找正向 skill）

1. **G5 Excel 业务数据处理**：输出是 xlsx/数值，最容易做确定性断言；组内按 LG / Sharp / CKD 再分。
2. **G2 代码审查/差异分析**：本地 diff + 公司编码规范，baseline 缺领域规则，lift 空间大且完全离线。
3. **G3 通用测试用例生成**：需求→用例，格式/覆盖度可检查；同组候选多，适合横向比选。
4. **G8-IR 遥控器配置**：脚本 + 样例 + 精确输出（`src/generate_ir_c.py`），是最“Tier3 友好”的小组。
5. **G1 Git 提交组**：最容易跑通，但 baseline 也强，必须用公司模板/严格规则制造差异。

> G10/G11/G12/G13 需要内网、飞书、Jira、Jenkins 或凭证，不适合作为正向 skill 的 Tier3 实验，但非常适合做 Tier2 重复检测和 Tier1 安全审计素材。
